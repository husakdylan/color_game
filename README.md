# 🎨 RGB Color Guessing Game

Un juego dinámico e interactivo construido con **JavaScript Vanilla** donde los jugadores ponen a prueba su conocimiento del modelo de color RGB.

## 🚀 Características
- **Generación dinámica de colores:** Algoritmos en JavaScript para crear combinaciones aleatorias de colores RGB en cada partida.
- **Modos de dificultad:** Selección entre modo Fácil (3 opciones) y Modo Difícil (6 opciones) adaptando la interfaz en tiempo real.
- **Feedback visual interactivo:** Respuestas inmediatas al usuario mediante animaciones de descarte y actualización dinámica del encabezado al acertar.
- **Manipulación eficiente del DOM:** Manejo de eventos (`addEventListener`), iteración de listas de nodos y actualización de estilos en línea.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica.
- **CSS3:** Estilizado, maquetación adaptativa y estados visuales (`.selected`).
- **JavaScript (ES6+):** Lógica del juego, funciones flecha, manipulación del DOM y manejo de eventos.

## 💡 Aprendizajes Clave
- Aplicación de conceptos de programación funcional y modularización de código.
- Gestión de estado del juego (dificultad, colores activos y color ganador).
- Normalización e interacción con valores de color en el DOM.
